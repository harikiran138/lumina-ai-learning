## AI Course Builder

The AI Course Builder allows Teachers to upload a syllabus or topic list and have the Assessment Agent generate:
- A structured module/lesson outline
- A set of quiz questions per lesson
- A set of flashcards per Knowledge Component
- A reading notes PDF or slide deck (PPT)

**Workflow:**
1. Teacher → Course Builder → "Generate with AI"
2. Teacher provides: course topic, syllabus text or PDF, target level (1st year / 2nd year / etc.), number of modules
3. Assessment Agent generates the full structure (background task, 20–60s)
4. Teacher reviews the draft — can edit any module, lesson, question, or flashcard
5. Teacher publishes the reviewed content

**Important:** The AI-generated content is always a draft for Teacher review. Nothing generated by the AI is published directly without Teacher approval.

## MLFD — Multi-Level Feature Detection (Video Analysis)

MLFD analyses uploaded lecture video recordings to generate an engagement and quality report for the Teacher. It runs as a background task after video upload.

### What MLFD Analyses

| Feature | Detection method | Output |
|---|---|---|
| Slide transition timing | Frame difference detection | Timeline of slide changes |
| Content density per slide | Text density of frame | High/medium/low density map |
| Pacing | Words per minute estimate from audio (optional) | Pacing score |
| Visual variety | Frame similarity clustering | Variety score |

### MLFD Output Report

Teacher receives a report with:
- Total lecture duration
- Number of slide transitions and average time per slide
- Content density heatmap per segment
- Suggested improvements (e.g., "Slide 7–10 spend 12 minutes on low-density content — consider adding a worked example")
- Engagement score (0–100) based on variety, pacing, and transition frequency

### MLFD Pipeline

```
1. Teacher uploads lecture video → MinIO (lumina-lectures bucket)
2. AI Engine receives MinIO object key
3. Frame sampling: extract 1 frame per 10 seconds
4. Per-frame analysis:
   - Text density (OCR on slide area)
   - Visual similarity to adjacent frames (cosine similarity on image embeddings)
5. Timeline construction
6. Report generation (structured JSON → formatted HTML report)
7. Report stored in MinIO (lumina-generated bucket)
8. Teacher notified: "Your MLFD report is ready"
```

### MLFD Does Not

- Use facial recognition or track individual students
- Record who is watching the video
- Send video content to any external API — all analysis runs locally in the AI Engine
