# PROJECT_OVERVIEW

## 🎯 Vision
**Lumina AI Learning** is a production-grade Learning Management System (LMS) specifically architected for Indian engineering institutions. It leverages advanced AI (RAG, BKT, DKT) to provide personalized learning pathways and automated, teacher-verified assessments.

## 🏗 High-Level Architecture
- **Backend**: FastAPI (Python) - Modular domain-driven design.
- **Frontend**: Next.js 15 (App Router / TypeScript) - Multi-tenant portal system.
- **Database**: Supabase (PostgreSQL) with Row Level Security (RLS).
- **AI Engine**: Hybrid models for knowledge graph generation and student state prediction.

## 👥 Stakeholder Portals
The system supports 12 distinct human and agent roles:
1. **Super Admin**: System configuration and multi-tenant management.
2. **Institute Admin**: Academic hierarchy (Departments, Semesters).
3. **Faculty**: Content creation, grading, and classroom management.
4. **Student**: Learning dashboard, assessments, and AI tutoring.
5. **Counselor**: Student well-being and performance tracking.
6. **Controller of Exams**: Assessment security and certification.
7. **Placement Officer**: Industry readiness and career mapping.
8. **HR / Industry**: Recruitment portal.
9. **Librarian**: Digital asset management.
10. **Parent**: Periodic progress alerts.
11. **Alumni**: Legacy networking.
12. **AI Tutor Agent**: Proactive student support.
